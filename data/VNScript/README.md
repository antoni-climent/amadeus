# Steins;Gate SCX Deciphering

To get the text from the steam version of Steins;Gate, you need to extract the script.mpk file, located in `STEINS;GATE/USRDIR/script.mpk`, which will generate the SCX files.This is done by executing `python decompiler.py <file.mpk or file.npa>`.
Then you can use [sc3tools 2.4.1](https://github.com/CommitteeOfZero/sc3tools/releases/tag/2.4.1) to extract the SCX files, converting them into txt files.
